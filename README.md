
# WhatsApp Bot using Selenium and Ollama

This project creates an automated WhatsApp bot that interacts with messages from WhatsApp Web. The bot reads unread messages, processes them using Ollama's API, and sends responses back through WhatsApp Web. It is implemented using Selenium WebDriver and the `ollama` Python library.

## Requirements

Before running the project, you need to install the following dependencies:

- Python 3.x
- `selenium`: For automating the web browser interactions.
- `webdriver_manager`: For managing the ChromeDriver installation.
- `ollama`: For processing the chat messages and generating responses.

### Install Dependencies

You can install the required dependencies using `pip`:

```bash
pip install -r requirements.txt
```

## Setup and Configuration

### 1. Install Chrome and ChromeDriver

Make sure you have Google Chrome installed. The `webdriver_manager` will automatically handle the installation of ChromeDriver for the appropriate version of Chrome.

### 2. WhatsApp Web

The bot will interact with WhatsApp Web. When running the bot for the first time, it will ask you to scan the QR code to log into your WhatsApp account. Once authenticated, the bot will monitor unread messages and send responses.

### 3. Ollama

Install [Ollama](https://ollama.com) and pull a model (`ollama pull llama3.2`). The bot uses `llama3.2` by default; set the `OLLAMA_MODEL` environment variable to use a different one.

## How to Run the Bot

### 1. Start the Script

After installing the necessary dependencies, simply run the `whatsapp_bot()` function by executing the script:

```bash
python whats.py
```

### 2. Scan the QR Code

Upon starting the bot, the script will open WhatsApp Web in a Chrome browser window. You will need to scan the QR code displayed in the browser using your phone's WhatsApp app to log in.

### 3. Monitor and Respond to Messages

Once logged in, the bot will monitor unread messages and respond to them automatically. The bot uses Ollama's chat model to generate appropriate responses to the incoming messages.

## Functionality Breakdown

- **start_whatsapp()**: Initializes the WebDriver, opens WhatsApp Web, and waits for the user to scan the QR code.
- **get_chats_with_unread_messages()**: Fetches all chats with unread messages by locating the relevant HTML elements.
- **open_chat()**: Opens the chat window for the selected conversation.
- **get_today_messages()**: Retrieves the unread messages from the current chat.
- **respond_with_ollama()**: Sends the unread messages to Ollama's API to generate a response.
- **send_message()**: Sends the response generated by Ollama back to the WhatsApp chat.
- **whatsapp_bot()**: The main function that ties everything together and runs the bot, continuously checking for new messages and responding.

## Example Workflow

1. **Initialization**: When the script starts, it launches a Chrome browser window and navigates to WhatsApp Web.
2. **Scan QR Code**: You will need to scan the QR code from your phone to authenticate.
3. **Chat Monitoring**: The bot will then start monitoring for unread messages in your chats.
4. **Message Response**: The bot extracts the latest messages, sends them to Ollama for processing, and sends the generated response back to WhatsApp.

## Troubleshooting

- **QR Code Scanning**: If the QR code is not being scanned within the time limit, increase the `time.sleep()` in the `start_whatsapp()` function to give more time for authentication.
- **WebDriver Issues**: Ensure that you have Google Chrome installed and the `webdriver_manager` is correctly downloading the appropriate version of ChromeDriver.
