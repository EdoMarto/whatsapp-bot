# WhatsApp Bot – Selenium + Ollama

An auto-responder for WhatsApp Web that runs entirely on your machine. Selenium drives a Chrome window
logged into WhatsApp Web, picks up chats with unread messages, and replies with text generated by a
local LLM through [Ollama](https://ollama.com), so messages are never sent to a cloud AI service.

## How it works

```
Chrome (WhatsApp Web) ──► find chats with unread messages ──► open chat ──► read last message
        ▲                                                                        │
        └──────────────── type reply ◄──── Ollama chat model (local) ◄───────────┘
```

The loop checks for unread chats every 10 seconds.

| Function | Role |
|---|---|
| `start_whatsapp()` | Starts Chrome (ChromeDriver is installed by `webdriver-manager`) and opens WhatsApp Web |
| `get_chats_with_unread_messages()` | Finds the chats in the sidebar that have unread messages |
| `open_chat()` / `get_today_messages()` | Opens a chat and reads its last message |
| `respond_with_ollama()` | Sends the message to the Ollama model and returns the reply |
| `send_message()` | Types the reply into the chat |
| `whatsapp_bot()` | Main loop |

## Getting started

Requirements: Python 3.9+, Google Chrome, [Ollama](https://ollama.com).

```bash
pip install -r requirements.txt
ollama pull llama3.2
python whats.py
```

Chrome opens on WhatsApp Web: scan the QR code with your phone (**Linked devices** in WhatsApp) within
15 seconds. The bot then starts answering unread chats.

To use a different model, set `OLLAMA_MODEL` (default `llama3.2`):

```bash
OLLAMA_MODEL=mistral python whats.py
```

## Limitations

- **Italian UI only.** The message box is located by its Italian label (`Scrivi un messaggio`), so
  WhatsApp Web must be displayed in Italian. For another language, change the `aria-label` in
  `send_message()`.
- **Fragile selectors.** Unread chats and messages are found by WhatsApp Web's generated CSS class names,
  which change without notice. If the bot stops finding chats, inspect the page and update the class
  names in `get_chats_with_unread_messages()` and `get_today_messages()`.
- **No conversation memory.** Only the last message of each chat is sent to the model.
- **Login timeout.** If 15 seconds is not enough to scan the QR code, increase the `time.sleep()` in
  `start_whatsapp()`.
